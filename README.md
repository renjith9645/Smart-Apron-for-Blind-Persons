# Smart Apron for Blind Persons

An AI-powered wearable assistive system designed to improve the safety, mobility, and independence of visually impaired individuals. The Smart Apron combines Raspberry Pi, YOLOv8 object detection, computer vision, IoT sensors, and voice assistance to provide real-time environmental awareness.

The system detects and identifies surrounding objects, measures obstacle distance, monitors gas leaks and hazardous conditions, and provides instant audio feedback to the user. By integrating artificial intelligence with embedded systems, the Smart Apron helps users navigate more confidently in indoor and outdoor environments.

### Key Features

* Real-time object detection using YOLOv8
* Obstacle detection and distance measurement
* Gas leak and smoke monitoring
* Voice alerts and audio guidance
* Raspberry Pi camera integration
* Emergency safety notifications
* Wearable and portable design
* AI and IoT-based assistive technology

### Technologies Used

* Python
* OpenCV
* YOLOv8
* Raspberry Pi
* ESP32
* Ultrasonic Sensors
* Gas Sensors
* Text-to-Speech
* IoT Communication

### Applications

* Assistance for visually impaired individuals
* Smart wearable healthcare systems
* Indoor and outdoor navigation support
* Hazard detection and safety monitoring

This project demonstrates how Artificial Intelligence, Computer Vision, and IoT can be combined to create affordable and effective assistive technology that enhances accessibility and quality of life for blind and visually impaired people.
